# ViaHorizon 0.9.0-dev

- Migrate from `.hnmod` to Horizon's native `.hmod` format. The launcher
  compiles the mod and its replacement functions against the prebuilt game.
- Pin Horizon 26.3 Nightly `0a875da` (November 20) and Horizon Mixins
  `e59da90`. This native package uses game internals and is exact-build only.
- Route translated multiplayer connections through an in-process pipe. No
  external proxy or Java runtime is needed. Online servers still use the
  account signed into Horizon and Horizon's session-service authentication.
- Choose a protocol in **Options → Mods → ViaHorizon → Config**. The default
  uses the existing `config.json` (auto detection for a fresh install).
  Per-server overrides in that file take precedence.

This is a development release. Single-player, LAN discovery, Realms and
Horizon friend tunnels follow the unmodified Horizon connection path. The
old `/vh` commands and 0.8-specific renderer/physics fixes that depended on
patching lower-level crates are not included.

See the [validation summary](../validation/0.9.0/summary.json).
